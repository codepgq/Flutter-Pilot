# phase-03：独立浏览器运行时与 HTTP 拦截

依赖：phase-02 passed。目标：G01、G04、G08、G09。验收基线：v1。

## 阶段目标

通过独立 Worker 管理 Chromium Context/Page，在导航前安装生产 HTTP 拦截；MCP 明确发现浏览器目标并执行生命周期操作，Flutter 使用路径不承担浏览器启动依赖。

## 任务与产出

- [x] P03-T01：按需私有安装浏览器运行时，锁定依赖与清单，提供进度、取消、损坏诊断和显式重试。
- [x] P03-T02：建立带认证/身份/代次、超时/取消的 Worker IPC，处理退出与资源所有权。
- [x] P03-T03：实现 Context/Page 创建、枚举、导航、刷新、关闭；固定运行目标，不附着日常浏览器 Profile。
- [x] P03-T04：实现生产规则匹配、正常转发/Mock/修改、正文限制、历史与首导航前安装；明确代理或直接拦截的单一后端选择。
- [x] P03-T05：提供生产 Worker 的 `test:web:http`，补能力与离线发现说明、故障隔离回归。

主要落点：Web Adapter、浏览器 Worker/资源清单、构建与打包配置、MCP schema/路由、网络历史模型及工作台运行目标页。
