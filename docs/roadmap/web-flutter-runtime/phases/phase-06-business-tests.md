# phase-06：Web 业务测试与证据关联

依赖：phase-05 passed。目标：G07、G08、G09。验收基线：v1。

## 阶段目标

Test Case v2 在固定浏览器运行时执行 setup、临时 Mock、主流程与本轮 HTTP/WS/UI 关联断言；失败、取消、断线及清理失败不能误报通过。

## 任务与产出

- [ ] P06-T01：将测试环境、时钟/事件基线、网络观察与清理从 VM 依赖分离，实现浏览器观察器。
- [ ] P06-T02：使用同一冻结快照装配 setup、主动作与临时 Mock；固定运行目标和 Context 锁。
- [ ] P06-T03：为 Web 接入有状态 HTTP Mock、请求参数断言、响应变量及唯一连接 WS 注入。
- [ ] P06-T04：建立下单成功/业务拒绝/后台状态变化夹具与旧历史、重复提交、取消、丢事件等反例，新增 `test:web:e2e`。
- [ ] P06-T05：完善 Test Run 证据、脱敏、清理重试、工作台及 MCP 离线说明。

主要落点：`src/testing/`、`src/workflows/`、SceneController、Adapter 观察接口、Web Worker、Test Case schema 与报告页。

## 固定验收标准

| ID      | 必需预期                                                                                                                                      | 验证方式                                       |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- |
| P06-A01 | 生产 run_test 可执行 Web Test Case v2；setup 创建连接后再启用本轮 WS；主流程基线排除 setup、旧在途请求、其他页/运行时和旧历史                 | 源事件/时间边界及隔离反例                      |
| P06-A02 | 下单成功用例检查原始请求参数、HTTP Mock 命中和响应 orderId，再关联 WS 与该订单行最终 UI；另一个 HTTP 200 业务拒绝用例按业务 code 得到正确预期 | test:web:e2e，两类正向业务测试                 |
| P06-A03 | 错误参数、错误 ruleId/响应、错误订单 WS、旧 pending、重复提交、采集丢失和窗口溢出均不能 passed；每种反例有可定位失败                          | 自动反例测试及终态/证据                        |
| P06-A04 | 临时状态在规定 Context/run 内共享、不同运行隔离；立即刷新可看到已提交状态，开启新 run 不继承旧 scenario，状态在响应投递前一致                 | 有状态 Mock 时序与跨 run 回归                  |
| P06-A05 | 运行中编辑源文件不改变冻结快照，运行阻止同 Context 环境修改和插入 UI；独立 Context 与 Flutter 不被同一个全局锁无故串行                        | 快照/锁集成及并存反例                          |
| P06-A06 | 取消、页面关闭、Worker 退出和 confirm 超时停止后续动作，已发未确认记录 uncertain，不重复提交/注入；UI/断言失败与环境错误正确区分              | 提交和注入计数、各终态回归                     |
| P06-A07 | 结束恢复本次临时规则/采集和资源；清理失败保留恢复入口并阻止受污染 Context 新运行，重试只清理不重放 UI                                         | 故障注入、恢复报告及资源核对                   |
| P06-A08 | Run 证据含实际目标、定义指纹、本轮网络/消息/业务关联 ID 与最终 UI，秘密参数递归脱敏；测试工具/指南/示例及 Flutter 业务测试契约同步通过        | 生产 schema、泄漏检查、协议/工作台和旧测试回归 |
