## 发现的问题及处理

- WDA 启动清理会卸载其他工具的 WDA。适配器 v3 在附着模式跳过 `startup.cleanupApps`，并拒绝旧 v2 安装回执；5 项驱动层回归覆盖预签名／模拟器启动路径、多 WDA、非附着对照、幂等、签名不匹配及旧安装 fallback。未在用户设备上进行破坏性卸载试验。
- 全局可见编辑菜单不能证明属于指定字段。菜单复用前和点击前均核验活动编辑器身份；Flutter 同时核验焦点、选区和实际编辑边界。真实 iOS 的无障碍字段框可能大于内部 `RenderEditable`，现同时提供所属 `TextField`／`CupertinoTextField` 边界，不以任意外层 Key 框替代。独立原生双输入框实测 A 的菜单不能用于剪切／粘贴 B，两字段文本保持原样。
- WDA `/source` 快照带有 `AppiumAUT` 包装层，XPath 查询树没有该层。iOS 元素查找移除仅位于开头的快照作用域，真实原生菜单验证通过，iOS／Android 路径有单测。
- MCP 客户端延长期限不能改变宿主原有 45 秒超时。认证、会话和参数校验后，宿主使用共享的 setup 660s、connect 240s、截图 85s 期限并留出 5s 余量；上述真实 IPC 长操作与取消验证通过。
- Unicode 编辑从完整原字符串计算字符簇边界，在聚焦前及执行前拒绝簇内光标／部分选区，整簇删除保留相邻字符。真实设备覆盖代理对、组合重音、ZWJ 家庭和旗帜。
- 原生 `/value` 保留当前插入点，无法保证追加到末尾。设备通道 `append` 在定位／输入前明确返回 `UNSUPPORTED_OPERATION`，能力项同步为 false；Flutter 追加显式使用 `backend=flutter`。真实中间光标、已有选区及纯原生字段均验证拒绝，未修改文本。
- Flutter 长截图按实际 VM 设备申请独占租约，仅同设备原生会话可复用。VM=A／native=B 且 A 被占用时拒绝、释放后允许及同设备复用由控制器回归覆盖，不把模拟双设备测试记为真实双设备验收。
- 只发送起终点的拖拽未能稳定触发原生排序。共享轨迹增加中间采样和拖拽释放前停顿，以实际排序／删除结果复验。
- 惯性滚动期间 Flutter 的命中测试可能暂时屏蔽子节点。设备触摸滚动后读取区域内 `ScrollableState.position.isScrollingNotifier`，等待停止，再检查目标；查找限定在指定区域后代内。
- iOS 驱动接受按键命令不代表 Flutter 编辑操作已生效。模拟器硬件键盘偏好关闭时组合键存在无效输入；剪贴板操作改为可见原生菜单，使用真实选区内点位打开菜单，并在点击 Copy／Cut 前核对选区未变化。方向键和修饰键仍依赖系统、App 与硬件键盘条件，未计作本轮设备通过项目。
- 早期未适配的 Appium 验收连接曾写入 Simulator 共享偏好；原始值无可追溯快照，本轮未擅自覆盖当前值。最终连接适配器跳过模拟器重启、GUI、偏好修改及其他 XCTest 进程清理，后续只处理本插件拥有的 WDA 和服务。

## 未覆盖与明确限制

- 原生输入框精确光标／范围选区及 append 明确不支持；Flutter 输入框使用编辑协议，追加显式指定 `backend=flutter`，结果注明执行方式。iOS 中英文以外编辑菜单需读取设备快照后显式点击。
- 硬件键盘组合键／方向键的业务效果、iOS 边缘返回、多行与密码框编辑菜单、不同系统语言、物理断线中断的设备效果尚未现场验收；对应路由、错误与释放有单测，不能因此标为设备通过。
- 中文输入法候选、WebView DOM、动作录制回放、完整设备管理和发布安装新版在本轮范围外。
- 操作已发出但结果不确定时返回 `uncertain=true`，不自动重试。分项 `supported` 表示接口与条件，不能替代本表的设备验收结果。
