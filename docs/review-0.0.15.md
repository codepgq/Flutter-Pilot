# 0.0.15 审核与验证

日期：2026-11-13。审核基线为 `46a4b9e`，范围包含本轮全部已跟踪改动、新增源码、测试、示例和文档；发布包同时包含此前已提交、尚未发版的移动交互功能。

## 已修复的问题

| 问题 | 修复与回归 |
| --- | --- |
| 动作耗时字段变化被当作布局变化，设备通道操作 Flutter 控件遭到误拒绝 | 只比较窗口尺寸、DPR 和 viewId，保留实际布局变化保护；覆盖稳定与变化布局 |
| 清空秘密参数后空字符串覆盖工作流默认值 | 有默认值的秘密参数留空时省略覆盖；覆盖工作台提交参数 |
| 提取对象中的嵌套凭据可能出现在失败 UI 证据中 | 递归收集敏感值并参与后续动态脱敏；覆盖嵌套对象和头部形式 |
| HTTP 匹配允许空 host/path，条件被静默当作未限制 | 在定义预检时拒绝空条件；覆盖无效定义 |
| Dio 的在途重复请求不可见，可能在重复响应完成前误报测试通过 | 请求开始即通知观察窗口，完成时按同一 ID 更新；开始事件不写入持久历史，覆盖真实延迟请求 |
| 有状态 Mock 的 Dio 覆盖不完整时仍继续测试 | 拒绝实例数量超限和部分实例接入失败，交由清理流程恢复环境 |
| MCP 请求在异步预检期间关闭后仍可能启动 UI | 获取运行所有权前检查原请求取消信号；真实 IPC 覆盖 Workflow 和 Test，已启动运行继续独立维护生命周期 |
| 测试清理失败后外部操作仍可污染待恢复环境 | 阻止外部自动化、热更新和环境修改，保留连接恢复及同一运行的清理入口；覆盖清理失败后的外部 tap 拒绝 |

缺陷回归均先复现问题再验证修复，未自动重放 UI、订单或 WS 事件。
